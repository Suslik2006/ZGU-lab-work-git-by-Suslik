Git Calculator / Git-калькулятор




A simple JavaScript calculator created for Lab #2 to practise Git and GitHub.



\### Features



\- `add(a, b)` — returns the sum of two numbers.

\- `multiply(a, b)` — returns the product of two numbers.



\### Download and run



Clone the repository:



```bash

git clone https://github.com/Suslik2006/ZGU-lab-work-git-by-Suslik.git

cd ZGU-lab-work-git-by-Suslik

```



No additional libraries are required. To run in a browser, open the developer tools (\*\*F12\*\*), select \*\*Console\*\*, paste the contents of `src/main.js` and press \*\*Enter\*\*.



Expected output:



```text

Hello, GitHub! Multiplication is available.

2 + 3 = 5

2 \* 3 = 6

```
